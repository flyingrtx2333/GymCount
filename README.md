# GymCount - 健身计数器

## iPhone 首版

在 Xcode 中打开 `GymCount.xcodeproj`，选择 `GymCount` scheme 和 iPhone 模拟器运行。最低支持 iOS 17。

支持在一场训练中记录卧推、深蹲、硬拉的多组训练。每组可直接输入重量与次数，也可逐次加减；完成本组后保存并开始组间休息，支持撤回上一组和跳过休息。切换动作前，未保存的次数会提示保存或放弃。

开始前展示上次该动作的各组数据，可沿用上次开始；训练中按当前动作的组序号沿用上次重量与次数；当前组已录入次数时，先确认再替换，取消则保留原输入。结束时将当前未完成组一并保存，历史详情展示各动作的组记录、总次数、时长与训练量。

设置中可调整 0–600 秒的休息时长，后台提醒由用户开启并授权系统通知。计时以截止时间计算，重启后恢复进行中的训练与休息。旧版历史保留原汇总信息，标注为旧版记录，不补造各组明细；旧版存储键保留用于恢复，新版活动训练与历史一起保存到 `phone.training.v2`。

配套版本支持将 Watch 普通训练历史传到手机：结束训练、打开应用或重连后自动补传，手机“训练记录”页可手动重试。原有手表汇总按原始时间和次数导入，不补造各组明细。手机填写的训练暂不回传手表，手机自动动作识别和 iPhone HealthKit 写入尚未实现。[同步与真实备份验证](docs/watch-workout-sync.md)

## 卧推计数 v8

配套版本使用 `GymCountSync.xcodeproj` / `GymCount Capture`。Watch 卧推改用融合运动数据与传感器时间，在推起回到顶端后确认；前两次一起确认，训练中为有延迟的估计，结束时核准。iPhone 采集详情使用同一模块复核，保留原始计数与人工标注。

5 条已有视频记录的总次数回放一致；完成节点仍有 4/25 处偏差超过半秒，尚未完成新版本的独立佩戴验证。数据不足时需人工核对。详见[实现与真实回放证据](docs/bench-watch-ios-v8.md)。

## 6. 使用方法

### 6.1 基本操作流程：
1. **开始锻炼**：选择锻炼类型（卧推/深蹲/硬拉），点击开始按钮
2. **计数方式**：
   - 手动计数：每次完成动作后点击+按钮
   - 自动计数：开启自动检测，手表自动识别动作
3. **调整重量**：点击重量区域进行实时修改
4. **结束锻炼**：点击停止按钮保存记录到历史
5. **查看历史**：在主界面点击历史记录查看统计图表

### 6.2 高级功能：
- **数字表冠操作**：在历史界面使用数字表冠切换运动类型
- **触觉反馈**：每次计数和完成时提供触觉提醒
- **屏幕常亮**：锻炼期间保持屏幕常亮，方便查看
- **HealthKit同步**：自动同步到Apple健康应用
