# GymCount - 健身计数器

## 项目信息
- **项目名**：GymCount
- **平台**：WatchOS
- **中文名**：健身计数器
- **英文名**：GymCount

## 标语
- **中文**：让手表数每一次努力
- **英文**：Your reps, tracked.

## 核心功能 ✅

### 已实现功能：
- ✅ **卧推计数** - 支持卧推动作计数
- ✅ **深蹲计数** - 支持深蹲动作计数
- ✅ **自动运动检测** - 基于加速度计自动识别运动动作
- ✅ **重量记录** - 记录和调整锻炼重量
- ✅ **锻炼历史** - 完整的锻炼历史记录和统计
- ✅ **数据持久化** - 使用UserDefaults保存数据
- ✅ **中英文本地化** - 完整的多语言支持
- ✅ **触觉反馈** - 计数和完成时的触觉提醒
- ✅ **用户界面** - 现代化的WatchOS界面设计

## 技术特性

### 架构设计：
- **MVVM架构** - 使用SwiftUI + ObservableObject
- **数据管理** - DataManager单例模式管理应用状态
- **运动检测** - CoreMotion框架实现自动计数
- **本地化** - NSLocalizedString完整支持中英文

### 文件结构：
```
GymCount Watch App/
```

## 使用方法

1. **开始锻炼**：选择锻炼类型（卧推/深蹲），点击开始
2. **计数**：每次完成动作后点击+按钮或使用自动检测
3. **调整重量**：点击重量区域进行修改
4. **结束锻炼**：点击停止按钮保存记录
5. **查看历史**：在主界面点击历史记录查看统计

## 设置选项

- **自动检测开关** - 启用/禁用运动自动检测
- **自动开始/停止** - 自动检测锻炼开始和结束
- **默认重量** - 设置默认锻炼重量
- **帮助文档** - 详细的使用说明
