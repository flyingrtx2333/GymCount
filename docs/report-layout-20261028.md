# 训练报告布局精修 · 2026-10-28

## 改动

沿用白金视觉规范。将详情标题与报告合为一个分区，次数、总用时、动作时长按相同列宽展示；其他已知指标采用紧凑标签／数值行。最大辅助字号自动改为纵向排列。

时间轴与组明细统一为“动作记录”，保留展开、选组和时间轴缩放；单动作报告不重复动作名称，组行统一文字基线、右侧次数与操作区域。组间间隔改为时钟与时长，恢复自动分组收进菜单，比较信息缩短。

手机修正仍用于顶部次数与重量。原始来源与分组提示保留，未知指标不补零；本次没有修改报告模型、计数算法、分组计算、健康数据或同步协议。
