# 杠铃深蹲站起完成算法 v1（2026-10-21）

版本 `squat-stand-return-20261021-v1`。替换云端以加速度小波峰计候选、手表以 X 轴稳定性切换计数的两套旧规则。普通训练、同步采集与云端采用相同的因果规则；Swift 与 Python 在全部真实导出的深蹲轨迹上逐次完成时间一致。

## 检测与反馈

仅输入传感器时间、融合重力、去重力加速度及旋转速度。不读取人工次数、Watch 次数、视频标注或人工训练起止区间。

1. 从约 0.5 秒的低运动窗口取得站立参考姿态，校正速度漂移。
2. 沿重力方向投影加速度，使用 0.08 秒因果滤波与 1.5 秒衰减积分估计竖直速度。符号与现有采样约定相同：下降速度为负。
3. 识别持续下降、底部速度反向及上升；下上阶段都须有足够的行程与速度。
4. 上升减速后，速度、腕部旋转和姿态回归站立范围，保持约 0.15 秒才完成一次。不能把同一动作的几次加速度反弹重复计数。
5. 缺口大于 0.25 秒、姿态切换过大或大幅转腕重置阶段，不跨缺口拼成动作。不在结束时补造一个完成点。

手表深蹲改为融合运动检测，训练与采集共用同一输入流。计数完成时间按采样时间保存，不再借用最近的原始加速度回调。震动在主线程单独检查会话与新鲜度，迟到超过 0.25 秒不补震；开始/准备/结束的自动点击反馈从卧推、深蹲入口去除。手动控件、错误和上传结果反馈保留。

新深蹲采集记录 `feedback_events` 与算法版本：它是调用 WatchKit 时的请求时间，不是硬件实际起振时间。旧载荷不补造反馈记录。后台可选字段已兼容深蹲，发布 App 前需先部署后台。

旧的无视频记录不能声称准确：3、4缺少融合数据，返回采样不足；5回放1次（人工4）；9、10没有确认完整周期，返回待核对（人工各10）；11回放1次（人工10）。这些记录没有逐次完成依据，原人工次数保持，不按标签补足次数。当前v1针对新上传的杠铃深蹲姿态，不能声称兼容所有旧采集动作。

卧推和弯举的现有真实记录，计数和事件时间与旧云端结果保持一致。深蹲有独立版本，其他动作不会因为深蹲升级被错误标记为旧算法。原有未提交的训练时长、历史等工作保留，本次没有提交或发布。
