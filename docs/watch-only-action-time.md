# 手表记录，手机查看；动作时长与总用时

## 产品范围

训练由手表首页选择动作开始并保存，手机负责同步、浏览和删除历史。手机默认打开训练记录，只保留记录/设置两个标签，不再展示新建手机训练和组间休息设置。空状态说明在 Apple Watch 开始训练，并提供同步入口。已有手机历史保留；尚未归档的旧手机草稿可在设置中保存，原写入模型暂保留以支持兼容，未删除旧数据。

## 时间口径

原 `duration` 继续保留开始到结束的总用时，在详情中明确显示“训练总用时”，不会追改旧记录。

新增可选的 `activeDuration`，显示为“动作时长（估计）”。只有现有卧推分析判为可估计时，才累计其传感器时间中的完整动作起止窗口；窗口取并集，休息、准备和保存后的等待不纳入，也不因流式重算重复累加。实时结果仍可能在结束核准时调整。

手动补的次数没有动作起点，因而使该场动作时长保持未测量。人工删除的误识别周期不再贡献计时，改动后先清空旧计时，再等待下一次分析核准；重量和人工次数保留。

深蹲/硬拉目前没有经过真实数据验证的动作时间边界，采样中断和旧汇总也缺乏可靠计时。它们显示“未测量”，不能用次数乘固定秒数、完成时间点之差或总用时冒充实际动作时长。所有既有计数检测器保持原样。HealthKit 原有的会话起止/时长写入未在本轮改动，不能把系统健身中的总时长说成已改为动作时长。

## 混合版本与历史保留

新字段为可选，旧手机和手表仍可解码原消息。手机升级后使用新的接收标识，使手表重新检查历史，修复“旧手机已回执但忽略新字段”时的补传缺口。日志只允许在 UUID、日期、动作、次数、重量和总用时完全相同的前提下，为空动作时长补充已测值；旧版重传不擦除已测值，冲突值拒收，删除标记仍优先。手机每次从日志合并时更新同一 Watch 汇总，其他历史保持不变。

## 当前验证边界

- 两个工程无签名编译通过；中英文编译资源检查通过。UI 导航回归改为手机仅查看模式，需区分测试包编译与真机执行。
- 对 11 条真实卧推采样回放，6 条满足原算法可估计条件并输出约 7.88–25.22 秒动作时长，其余 5 条不填数字。它们的总用时为约 13.04–50.11 秒。8 条深蹲均保留未测量，不以实验计时冒充有效结果。
- 同一回放检查字段编解码、原子持久化、重启、混合版本补充和旧版重传不擦除。捕获文件不含负重，隔离协议检查将负重 0 明确作为未指定值，不把采集文件导入用户的训练历史。
- 82 条真实手表历史的独立导入回放通过，原字段、未测量状态、重复去重、重启、日志恢复、删除不复活均保留。回放只写隔离目录，不改原数据。
- 尚无逐次动作开始时间的视频真值，也未进行新版本佩戴、手机显示和双端实际传输验收。不能将采样回放、编译和字段检查当作实际动作计时精度或真机同步证明。

本改动尚未提交和发布，TestFlight 1.1.3 (30) 仍为此前版本。
