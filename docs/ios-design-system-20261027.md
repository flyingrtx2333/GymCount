# iOS 视觉规范落地 · 2026-10-27

## 本轮范围

此前共享了白金色板及部分组件，同级字号、正文边线、分区和操作反馈仍由多个页面单独定义。本轮将规则集中至 `RecordStyle.swift` 的 `Studio`、`RecordPageHeader`、`RecordNumberText`、`RecordSectionTitle`、`RecordInlineState` 和三类按钮样式，完整规格见 [iOS 视觉规范](ios-design-system.md)。工程约定已加入 `AGENTS.md`。

- 记录、趋势、设置复用首页标题栏与筛选；16 点正文边线，44 点操作触控，记录行至少 68 点。
- 页面、分区、正文、指标、单位、坐标字体按语义角色复用；字体随系统缩放。详情指标与趋势指标使用相同的数字／单位层级。
- 设置改为普通列表与细分隔线；帮助及补记分区间距归一。系统导航、日期选择、恢复表单和文件面板保留原生规格。
- 保存、标记、上传使用同一主按钮，次操作与文字操作共享尺寸及按压反馈。减弱动态效果时取消按压缩放；编辑器底部保存操作仍随键盘安全区布局。
- 已有内容中的缺失图表数据改为紧凑状态；保留整页空状态。没有改动计数算法、训练记录、同步协议及上传进度计算。
- 采集、录像核对、上传、时间轴与开发者入口沿用同套字号、边距、圆角和按钮；多传感器曲线与错误继续使用有含义的语义颜色。
