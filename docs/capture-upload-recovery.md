# 采集上传和次数确认修复

截图同时显示旧权限失败和上传完成。CollectionView 分别渲染 WatchCaptureLink 与 CollectionStore 的提示，旧提示未随本次上传清除。改为统一显示 CollectionStore 的当前结果，连接和授权消息也写入该结果通道；手机上传通过 WatchConnectivity 同步当前上传结果与触感。

上传前必须确认实际次数，实际次数初始为 0；上传时禁用次数编辑和重复上传。Watch 上传失败后保留文件，并恢复本组核对界面与已填写次数，允许继续修改。HTTP 409 明确说明同一组已存在但内容不同，应在网站修正，避免覆盖已有原始采样。删除本地草稿和重试待上传均先确认。网络结果不确定时不删除本地记录。

网站每行提供修改次数和删除。修改次数入口定位到核对表单；修改继续保留原始采样、输入哈希、算法结果和标注历史。删除需要确认，只有站长权限可执行，事务中删除指定记录并写入审计事件。删除失败保留记录和弹窗。

验证：27 项后端回归、11 项网站测试通过；Watch 模拟器 2 项真实 CollectionStore 回归通过（HTTP 500 后可修改、成功后移除队列、超时后保留、明确丢弃）；iPhone 2 项导航及同步启动回归通过。独立示例页在浏览器核验修改保存、删除取消、删除成功、桌面和 390px 手机弹窗。示例页已移除；未修改或删除生产采集数据。真实手表与网络波动需更新后复测。
