# PowerReps iOS 视觉规范

本规范覆盖记录、趋势、设置，以及训练详情、补记、时间轴、同步、采集与上传。实现入口为 `GymCount iOS/RecordStyle.swift` 中的 `Studio` 与共享组件。页面按信息角色引用样式，不另设同级字号、正文边距或按钮形状。

## 颜色

跟随现有白金配色：暖白／炭黑背景、墨色／暖白正文、香槟金主操作与选中状态、低对比辅助文字和分隔线。页面统一使用 `Studio` 的自适应颜色。

系统错误、警告及多传感器曲线继续使用具有实际含义的语义颜色。动作分布的不同色阶保持同一低饱和色系。

## 文字

| 角色 | 共享入口 | 标准字号与字重 |
| --- | --- | --- |
| 首页标题 | `Fonts.title` / `RecordPageHeader` | title2，22，semibold |
| 模态状态标题 | `Fonts.modalTitle` | title3，20，semibold |
| 同级分区标题 | `Fonts.section` / `RecordSectionTitle` | subheadline，15，semibold |
| 正文与字段 | `Fonts.body` | subheadline，15，regular |
| 紧凑菜单与文字操作 | `Fonts.control` | caption，12，medium |
| 主要按钮 | `Fonts.primaryAction` | subheadline，15，semibold |
| 汇总指标数字 | `Fonts.metric` | title2，22，medium |
| 列表次数数字 | `Fonts.rowMetric` | title3，20，medium |
| 单位、辅助信息 | `Fonts.caption` | caption，12，regular |
| 图表坐标与密集刻度 | `Fonts.axis` | caption2，11，regular |

全部使用系统语义字体并响应字体缩放。数字统一等宽数字；指标通过 `RecordNumberText` 区分数字与单位，缺失值保持“—”。不同字体环境按系统实际度量，不依赖固定像素高度裁切。

系统导航栏、键盘和文件选择器采用原生规格。实时采集的大号计数具有独立的远距离读取用途，不充当普通统计指标样式。

## 布局与容器

- 正文、图表、记录行、详情、表单与弹窗主边线均为 `Studio.inset`，16 点；系统文件面板及系统导航栏保留原生安全区。
- 标准首页标题栏至少 44 点，标题在左、操作在右；辅助字号改为标题在上、操作在下。标题不因操作区高度变化而上下移动。
- 分区间距统一 16 点，内部常用间距 8 点、相邻字段 12 点、标题与数值 2 点。列表记录行至少 68 点，字体放大时自然增高。
- 主页面使用开放内容和细分隔线。设置采用紧凑普通列表，减少厚重的大圆角分组；原生编辑、恢复校验等表单可以按任务保留分组。
- 分隔线 0.5 点；输入和按钮圆角 8 点；播放器等媒体容器圆角 12 点。图表标记圆角独立按图形表达处理。

## 操作层级

- `StudioPrimaryButton`：金色填充、15 点 semibold、圆角 8 点、触控高度至少 44 点，默认按内容宽度。用于保存、上传、标记等当前任务主操作。
- `StudioSecondaryButton`：细描边、相同字号、圆角与触控高度。用于需要独立承载的次要操作。
- `RecordPressStyle`：轻量文字／图标操作，至少 44 点触控范围；不把整行文字菜单扩展为大面积实色按钮。
- 统一按压反馈：0.16 秒 ease-out、轻缩放至 0.99、按下透明度 0.76、禁用透明度 0.4；减弱动态效果时取消缩放动画。
- 删除等破坏性操作保留系统语义色和原生确认，不以品牌金代替。

## 空状态与状态反馈

- 整页没有记录时使用原生整页空状态。
- 已有内容中的单个图表缺数据时使用 `RecordInlineState`：15 点文字、小图标、至少 56 点高度，不占据大块屏幕。
- 同步与上传显示真实状态、进度、错误和可执行重试。保留必要的不确定性标签，不添加说明性填充文案。

## 落地约束

新增页面和修改同级组件时复用以上入口。规范与实现一起更新；视觉差异必须有信息层级、交互任务或系统控件的依据。

验收使用真实原生页面：检查中英文、大小屏、浅深色、辅助字号、底栏遮挡、滚动末尾、编辑键盘、导航返回及按钮禁用状态。构建、原生检查、真机验收和发布分别记录。验证凭证见 [视觉规范落地记录](ios-design-system-20261027.md)。

## 可折叠与可变窗口

布局依据当前窗口安全区和可用空间，避免主屏幕尺寸、设备型号和固定方向判断。三个入口使用原生 TabView；Duo 的侧边栏由系统排列。记录通过 NavigationSplitView 在单栏与列表／详情双栏之间切换；宽屏当前选择使用淡金底色。趋势在普通宽屏显示两列，大字体和窄屏回到一列；补记表单保持可读宽度。折叠展开保留当前记录、筛选和编辑状态，不通过重新创建整页完成布局切换。详见 [Duo 适配](ios-duo-20261103.md)。

### 宽屏留白与图表层级

常规宽度使用共享 `recordCanvasSpacing`：侧栏正文总边距 24 点，主内容总边距 28 点，顶部留 8 点；紧凑宽度保持 16 点。内部行高与字号沿用原规范，不随屏幕放大。原生分栏只指定理想宽度，不锁死最小／最大宽度，让系统适配半折叠。

趋势按概览、主图、辅助统计排列。主图横向使用内容区域，宽屏提高到至少 190 点；下方日历与动作／重量统计两栏展示，大字体和窄屏回到一栏。iOS 27.1 上按当前视图的 division 保留区域调整辅助列宽与中缝；无有效保留区域时沿用共享 28 点间隔，不依据设备型号或屏幕常量。
