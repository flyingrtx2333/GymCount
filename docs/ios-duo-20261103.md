# iPhone Duo 原生适配

## 实现

- iOS 最低版本保持 17，生产目标仍为 iPhone；Xcode 27.1 / iOS 27.1 SDK 构建。
- 原生 TabView 承载记录、趋势、设置，随系统调整为侧边导航，内容遵守当前窗口的安全区。
- 记录页使用 NavigationSplitView：窄屏列表进入详情，宽屏记录与详情并排。选择保存在父视图；宽屏选中行用淡金底色标识。详情按记录 UUID 管理身份，避免切换记录短暂沿用上一条时间轴。
- 趋势采用稳定视图树的自适应网格，普通宽屏两列，大字体和窄屏一列。图表日期分组声明日／周／月单位后按可见分组缩放柱宽，纵轴按当前可见时间范围缩放。
- 补记表单限制阅读宽度；采集和播放器按可用空间调整高度。两个 iPhone 工程开放横屏。
- 不引入 UI 依赖，不修改计数算法、训练数据格式或手表通信协议。

## 宽屏边距与趋势精修

沿用同一套自适应页面：常规宽度侧栏边距 24 点、主内容 28 点、顶部补 8 点，紧凑宽度仍为 16 点。分栏内的 size class 可能为 compact，因此记录页从整个窗口传入宽屏状态；不会为 Duo 复制独立页面。详情的时长、组明细、备注与上方指标统一左边缘。

趋势按概览、全宽主图、辅助统计排序。宽屏主图至少 190 点；日历与动作／重量两栏，在 iOS 27.1 根据当前 division 保留区域调整列宽与间隔。窄屏与大字体使用一列。原生分栏只指定 352 点理想宽度，半展开时仍由系统安排两侧区域。
