# 健康权限路径引导

用户已在实体手表上找到权限入口，要求授权失败弹窗及设置页明确说明。

- 手表授权失败弹窗写明「在手表本机打开」，列出「设置 → 健康 → 数据来源、App 和服务 → 健身计数器」，要求开启「允许写入」中的「体能训练」，并说明应用可能显示为 PowerReps。
- 手表设置的「运动圆环」区域始终提供「健康权限怎么开」入口，即使关闭圆环同步也可查看。帮助页与弹窗共用同一份路径及操作说明；帮助页使用固定标题和原生关闭按钮。
- iOS 设置增加「权限与帮助 → 手表健康权限」，提供相同路径、目标开关及返回采集页检查权限的步骤。
- 未增加采集页常驻长说明，未改变健康授权请求范围或采集算法。

验证：iOS 模拟器 Release 双端构建通过；新增帮助入口导航测试通过，结果 `build/PermissionGuidePhone.xcresult`。40mm、46mm 实际帮助页及 40mm 实际 CollectionView 原生失败弹窗在隔离副本中截图核验，证据位于 `build/PermissionGuidePreview/`。弹窗状态使用注入的拒绝结果，未请求系统健康权限、启动传感器或上传；副本已卸载。此验证不代表真机授权成功。
