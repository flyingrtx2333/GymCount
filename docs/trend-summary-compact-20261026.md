# 趋势摘要精简 · 2026-10-26

针对用户圈定的趋势摘要区域，将原来的指标、自然语言时长、普通记录数和独立坐标单位收成一行：左侧“总用时”指标菜单，右侧“2:09”。菜单完整项和辅助功能仍保留原指标含义；“动作时长（估计）”在紧凑标题中写为“估算时长”。

时长不足一小时用`m:ss`，满一小时用`h:mm:ss`。图表时间刻度从实际秒数按相同格式显示，删除独立的“分钟”标题。次数、重量仍保留本地化单位。未知时长为`—`，已知零时长为`0:00`；时间轴最小跨度为两秒，避免零值区间出现重复的半秒整数标签。

横排通过原生ViewThatFits测量空间，窄屏或大字号自动纵排。点选日期后的跳转与清除仍单独保留；仅部分记录有时长时保留覆盖状态，不将缺失数据补零。底部日期汇总、首页、手表、存储和算法不改。
