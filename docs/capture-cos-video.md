# 录像上传与网站查看

配套项目 `GymCountSync.xcodeproj` / `GymCount Capture`。iPhone 的“上传录像与采样”使用同一采集 UUID 关联传感器数据与无音频 MOV 录像，手机文件保留。

- 先上传运动采样，取得仅用于该记录的短期录像上传授权。云端重复上传相同采样返回同一条记录；不会覆盖网站人工修改过的次数。
- 手机分块计算文件 MD5，使用带文件大小、MD5、类型和 private ACL 的签名地址直传到现有 COS。COS 凭据留在服务器；录像不经过业务服务器上传体积限制。
- 服务端检查对象大小和 MD5 后关联录像、逐次参考标注、视频与采样的时间偏移、时钟往返延迟及人工修正。仅两部分完成才报告上传成功。
- PUT 回应丢失时，重试先核验已存在的对象；同一录像不再重复传输或新增记录。已有记录改过本地次数时，补传结束提示到网站修改次数。
- 网站“健身采集 → 查看”展示原生播放器。仅网站所有者可以获取短期播放地址；匿名接口返回 401，COS 匿名读取返回 403。加载或播放失败提供重试。
- 删除云端记录同时删除已关联 COS 录像；录像删除失败时保留数据库记录。云端重算保留录像元数据和人工次数。
- 旧版已有本机录像的记录可直接补传；不要求重新采集。旧版上传后若修改过本地次数导致采样冲突，应恢复首次上传的次数再补传，随后在网站修改次数。

## 接口

`POST /api/v1/gymcount/sessions` 返回 `id`、`session_id`、`video_upload_token`。`POST /api/v1/gymcount/videos/prepare` 与 `/complete` 使用专用 Bearer 授权；上传授权不能作为登录令牌。`GET /api/v1/admin/gymcount/sessions/{id}/video` 提供所有者专属临时播放地址。

单条录像最大 512 MiB，最长 190 秒。PUT 签名有效期 30 分钟，附件授权与网站播放地址有效期 1 小时。录像元数据存入原记录 JSON，无数据库结构迁移。

## 验证

12 项后端、12 项页面回归通过；双端 Release 构建、归档及最终 IPA 签名与版本配置检查通过。相同 Native Foundation 上传器实际调用已发布 API，完成私有 COS 文件上传、关联及重复提交。真实 COS 校验通过文件大小/MD5检查、匿名拒绝访问、授权 Range 播放及篡改文件拒绝。桌面和手机尺寸页面可播放真实 COS 验证录像，无页面报错或页面横向溢出。

验证用的非训练记录和 COS 对象已删除。以上验证不证明真机相机、Watch 无线连接或计数算法准确率；用户的 5 次记录 #19 仍需安装新版本后从手机补传原录像。
