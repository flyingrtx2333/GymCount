# 趋势统计

## 设计

延续白金极简与原生 Charts。使用同一动作及日期筛选，排列为累计概览、训练热力日历、原有日期趋势、动作分布、重量分布和可展开的日期汇总。图表用香槟金表达数据密度，不加入无依据的评分和建议。

新进入趋势默认全部动作、全部时间，记住指标和汇总显示方式；本次访问中切换分页不会丢失筛选。应用回到前台时重新计算日期范围和连续天数。

顶部用一排简短指标显示记录、次数、天数与已知用时，大字体改为两列或单列。最常练动作与常用重量合入已排序的动作、重量分布，保留真实频次与单位。热力格按训练记录数着色，7 行代表周一至周日，支持近一年及历史年份。日期明细点选后出现，可进入当天记录或清除选择；连续天数收进已有汇总展开项。

## 统计口径

- 训练记录按保存记录计数，不把一条汇总推测为若干组。训练天数按当前日历的本地日期去重。
- 动作分布可查看参与记录数或动作次数。混合动作记录对每个实际包含的动作各计一次参与记录，次数按真实组分别合计。
- 最常练动作按参与记录数排序，相同时按已有动作顺序稳定排序，并同时展示记录数和动作次数。
- 常用重量只使用实际非 imported 组明细，按已记录组数计频次。旧汇总只有最大重量，单独显示“常见最大重量”和正值重量的“最大重量分布”，不把最大重量当作每组重量。
- 重量分布显示频次最高的八个重量，以重量升序排列；图表与按钮均可选择具体重量查看频次。旧汇总中的 0 不列入重量分布。
- 累计时长只累加已知时长。缺失时不生成 0，也不将整场时长分摊给没有记录时长的组。
- 连续训练按日历逐日推进，避免夏令时偏差；当前连续天数允许今天尚未训练时从昨天开始。未来日期及零次记录排除。2026-10-27 起与手机记录页、Watch 首页和晚间提醒共用 `TrainingStreak`；趋势仍遵从当前动作及范围筛选。
- 热力格、概览、时间趋势、动作与重量分布采用相同筛选。只有日期日历显示的近一年／历史年份属于日历自身的查看窗口。

## 验证

统计脚本 `scripts/verify-training-insights.swift` 读取既有真实历史，可选读取实际训练快照。真实旧数据没有组明细时，不构造组进行测试。

82 条真实历史核对得到 323 次、12 个训练日、已知时长 2433.926 秒。动作分布、最大重量分布、10 个日期范围、本地日期及连续天数与来源一致。真实来源没有组明细，常用组重量分支尚无真实历史覆盖；不为此构造训练组。

在独立预览安装中完成原生检查：大屏默认累计概览、日历点选并进入当天记录、动作筛选及重新进入默认值；小屏英文重量选择与近 30 天筛选；深色英文最大辅助字号各区块可达、日期选择和重量选择。最终月份标签修复后，另完成日历横向滚动及年份切换检查，共四个原生场景通过，运行时告警为零。实际截图、各阶段源码摘要、执行结果及运行时检查保存在证据目录。

独立 iPhone、旧采集工程及配套 UI 工程构建通过，沿用既有采集闭包捕获及 AppIntents 警告；中英文 57 个界面文案键完整。82 条真实记录的存储回归通过迁移、重复导入、手机修正保留、删除不复现、重启与备份恢复。新增统计没有改动计数算法。

验证证据位于忽略目录 `evidence/training-insights-20261027/`。本轮没有新增真机交互、WatchConnectivity 传输或人工 VoiceOver 验证；不发布，不覆盖真机安装。


## 字体与信息密度调整

2026-10-27 按页面反馈仅收紧趋势排版：概览数字 28→22pt、单位使用 caption；去掉重复的概览标题。横向边距 20→16pt、区块间距 20→10pt，并移除分隔线的额外上下边距。动作分布使用 15pt 标题及紧凑行，日期趋势和重量分布减少固定图高。

热力格在常规字号下 18→14pt，格间距 5→4pt；较大字号保留 18pt 格子，月份区域保留 22pt。日期、年份、筛选、动作和重量入口保留至少 44pt 操作范围。系统字体缩放、换行与既有月份完整显示逻辑保留，未改统计模型、记录数据或计数算法。

复用两个既有原生场景：大屏中文的日历滚动、年份切换与重量选择，小屏深色以及英文最大辅助字号的页面滚动、日期弹窗与重量选择。实际大屏首屏可同时容纳累计概览、完整日历和时间趋势图；本轮证据保存于 `evidence/training-insights-20261027/native/density/`，构建与输入摘要在同级 `density/`。本轮没有发布或新增真机验证。


## 减少常驻文字

2026-10-27 按继续反馈合并重复信息，不再缩小字体。概览使用“记录／次数／天数／用时”四项；默认一排，较大字号两列，辅助字号单列。移除重复的独立常练／常用块，原动作分布仍按真实记录频次排序，原重量分布仍区分已知组重量和汇总最大重量。记录“条”、动作“次”和负重单位保留。

日历默认只显示格子；点选日期或打开日期选择器后显示简短日期和次数，可清除。默认隐藏最新日期明细和连续天数文字，连续值放在既有汇总展开项中。时间／次数趋势默认不重复顶部总值，图表点选后仍显示选中范围数值。必要空态及未知时长标识保留。

五个界面／词条文件与构建输入一致，50 个提取词条中英文无缺失；三个工程构建通过。复用大屏日历与分布、小屏深色及英文辅助字号两个原生场景，通过且运行时告警为零。真实大屏首屏可看到概览、日历、时间趋势和动作分布；没有改变统计、存储或计数算法，没有发布。最新证据：`evidence/training-insights-20261027/text-reduction/` 及 `native/text-reduction/`。


## 动作细环图

2026-10-27 按已选方向将动作长条替换为原生 Charts SectorMark 细环图，代码仅修改 `GymCount iOS/RecordInsightsView.swift`。常规字号左侧为 104pt 环图、右侧为图标／名称／数量，较大辅助字号改为纵向并保持左对齐。图中不叠加百分比或中心总数，图例保留至少 44pt 操作区域，点击继续筛选；记录数／动作次数菜单保留。

颜色固定对应动作，适配浅色及深色；沿用与 Watch 相同的运动矢量资源并按环图颜色着色。零值不生成有色扇区，全部为零时显示中性轨道，图例仍显示真实零值。记录模式按各动作参与记录数的合计绘制比例，混合动作的一条记录可参与多个动作；次数模式按实际动作次数。环图作为信息图，VoiceOver 使用具备完整名称、数量和筛选提示的原生图例按钮。

使用真实 82 条历史复用两个既有原生场景，额外捕获模式切换、单动作及零次数状态，没有新增持久化测试方法。大屏中文验证图例筛选与记录回读；小屏深色及最大英文辅助字号验证布局、日期弹窗与重量选择。最终两项通过，运行时告警为零；109 个 iOS 产品输入与构建副本一致，三个工程构建通过。中间对齐迭代保留在 `donut/native-first-pass/`，最终截图和原生结果位于 `donut/native/`。没有发布或覆盖正式设备数据。
