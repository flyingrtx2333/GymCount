# Watch 重量输入页

2026-10-27 完成，已随 TestFlight 1.1.5（46）发布。详见 [发布记录](testflight-1.1.5-46.md)。

训练中、设置中的器械重量与体重编辑共用原生输入页：单层重量输入框、框内单位、两个快捷加减和顶部文字保存。保留白金配色，去掉大号静态数字、四个拥挤的调节按钮及整行保存胶囊。

支持小数及系统键盘输入。输入使用当前语言的数字分隔符，完整解析后校验有限数和原有范围；负数、非数字尾缀等非法输入不允许保存，显示就地错误。加减按钮遵守上下限。进入页面读取当前实际重量，本地编辑只在确认保存后回传，返回不改原值。

训练页及设置行保留小数显示，避免 72.25 被显示为 72.2；补充当前重量和调节步长的读屏值，主要触控区域至少 44 点。
