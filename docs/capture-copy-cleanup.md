# 采集文案与上传状态

手机校时不再显示轮数，开始按钮统一显示「正在准备采集…」。去掉录像采集页的重复进度、长说明、训练页说明小字、空记录页描述和开发者工具页脚。次数调整仍自动保存，移除重复的保存按钮。授权引导、采样等待、异常原因及重试操作保留。

采集记录每行日期右侧显示上传状态：没有云端记录 ID 时为「未上传」；采样已确认但录像未确认时为「仅采样已上传」；云端记录 ID 与录像完成时间均存在时为「已上传」。状态使用每组本地保存的上传回执，不会将部分上传显示为全部成功。

双端编译通过；既有手机页面导航回归通过并保留六张实际模拟器截图。最终发布安装包核验 iOS、Watch 版本及签名、HealthKit、后台训练配置。此次改动未扩大算法或传感器逻辑，未据此声称完成真机采集验证。
