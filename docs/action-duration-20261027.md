# 动作时长修复

列表曾直接显示从开始到结束的整段计时，忘记结束时，空闲也被当成运动时间。2026-10-27 改为：列表只显示已知动作时长，趋势及累计概览默认使用动作时长；详情保留“训练总用时”，趋势也可主动选择总用时。手动补记使用用户填写的时长，缺失值不补零。

Watch 深蹲现在保存原有检测器每次下蹲至站起的区间，并累加区间长度，排除区间外的准备与空闲。重叠区间只计算一次；未完成动作不纳入。停止时补收的已完成区间不触发完成震动。本轮没有修改动作计数的阈值和触感触发条件。手动增加次数没有可核对区间时，动作时长保留未知。

手机可从保留的连续真实采样恢复时长，但要求当前检测周期数、原始次数及完成打点逐一一致。计数被手机修正后，与原始次数不一致时不继续展示旧动作时长。完整计时、原始汇总、手机修正及删除标记保留；先持久化再回执。

## 验证边界

- 16 份保留的真实传感器时间轴通过导入、文件先到、重启、重复同步、次数修正、备份恢复和删除回归。当前检测器重放识别出 62 个动作周期；其区间总和均未超过原始整段计时。当前检测输出的动作时长通过双端协议往返、混合版本重放及持久化检查。
- 这些旧时间轴的来源次数／完成节点没有全部匹配当前重放结果，因此未强行填入动作时长。该结果不表示它们没有运动，也不把重放当作视频标注验证。
- 82 条真实历史的累计、日期范围、时区、动作筛选、天数和未知值统计通过；未把汇总最大重量扩充成实际组明细。
- 真实卧推时间轴通过校验、手机修正保留、备份 v1/v2、冲突拒绝、删除不复现及写入失败回滚检查。
- 原生页面检查另外发现切换动作筛选时，Charts 环图过渡会出现 NaN 并崩溃。环图数据集合变化时重建绘图、关闭扇区数值插值，零总量时只保留底环；其他页面动效保留。
- 真机佩戴时长、触感与双端传输未新增实测。检测区间属于算法估计，不声称已独立验证真实动作起止精度。

发布及最终原生检查凭证见 [TestFlight 47](testflight-1.1.5-47.md)。
