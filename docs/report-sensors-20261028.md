# 整场报告传感器 · 2026-10-28

## 问题与改动

整场训练已把各段采样保存在手表 `WholeWorkoutSamples`，但原同步只发送报告；手机仍按旧单条训练 ID 查时间轴，并在整场报告隐藏缺失状态。因此此前报告截图只有汇总和动作时间轴。

- 手表沿用逐段原始 `WorkoutTimeline` 文件，新增独立段 ID、接收能力协商和接收端身份校验。父报告确认落盘后才传采样；传输完成不等于接收成功，只有手机持久化回执才确认。原始文件继续保留。
- 手机先保存 Watch 临时文件到接收端隔离收件箱，支持父报告迟到、重复接收、重启后重试和删除标记优先。按原始父报告校验段范围、动作、次数和重量；手机修正、拆组与合组不改来源采样。
- 原始采样按段保存与读取，浏览时只加载选中段；曲线只对绘制点保留极值压缩，不改原始文件。整场时间标签使用已知采样起点；未知起点明确使用段内时间。
- 训练详情直接显示传感器：加速度、去重力加速度、旋转速率、姿态角、重力和实际存在的融合磁场。支持逐次打点、选点读值、15／30 秒窗口与分段切换；人工标注和震动请求只在文件确有记录时显示。
- 训练记录备份升级为 v4，包含分段采样，接受旧 v1–v3。合并恢复保留当前同 UUID 内容，本机删除优先；失败只回滚本轮新增文件。

原生操作发现并修复两处循环布局：图表通过 PreferenceKey 回写几何状态，以及异步加载 task 绑定条件 Group。图表现在直接使用 ChartProxy 几何，加载绑定稳定 VStack。最大辅助字号下，打点行按实际内容撑高；时间和清除按钮保持同一行、选中图标保留同宽，避免选点时突然增高、文字换行引起列表跳动。
