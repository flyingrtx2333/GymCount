# 采样中断修复

线上 #8、#12、#13、#14 的四份手表独立采集记录有真实时间缺口，且约 565 个旧回调集中恢复；同一次暂停同时影响加速度和融合运动。独立入口没有启动 HKWorkoutSession，手机同步入口才启动。这个明确的生命周期缺陷与暂停后恢复的迹象一致；历史记录没有系统状态日志，不能证明每次暂停的唯一触发因素。

手表两种入口统一取得训练写入权限，启动训练会话并等到 running 后再开始传感器；启动中禁止重复点击，离开独立采集页面取消尚未完成的启动。采集结束统一释放会话。会话意外暂停或结束时停止采集并保留有效采样。

加速度与融合运动分别记录最大传感器时间间隔、最大回调延迟；每 0.5 秒检查已有缺口及超过 1 秒的采样停滞，首次异常振动提示。记录起止及会话/界面状态写入系统日志。结束时有缺口或异常会话则在现有备注字段保存简短诊断，保留数据而不补造缺失点。无需扩展上传协议。

记录时长改为实际经过的传感器时间，不再仅取最后一个收到的点。云端 v6 同时检查内部缺口与首尾覆盖（0.25 秒），未覆盖记录末尾的部分采样返回未知，不输出正常完整计数。

真实数据验证：五份线上记录的十条流中，四份中断全部检出，完整 #19 无误报。云端重放全部 17 份原始数据，#19 仍为 5 次；裁掉真实记录的起始或末尾片段均被判定采样不足。权限、保存及上传等十项手表回归通过；双端编译通过。以上不等于已验证真机熄屏连续性，需要用户更新新包后实际采集验证。
