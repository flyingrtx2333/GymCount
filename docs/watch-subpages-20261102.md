# Watch 子页逐项统一 · 2026-11-02

本轮接续顶部统一，修正此前遗漏：带返回按钮时标题未显示、历史动作选择／高级设置仍用旧导航标题、历史重复返回行、重量英文名称挤掉数值，表单底部操作区域占位和遮挡，以及反馈空状态按文字宽度收窄整个页面。

- 所有业务页面使用同一个撑满宽度的 44 点 `gymNavigationTitle` 头区，不再为有无返回按钮使用不同的布局。子页为左上角返回箭头＋紧凑标题，保留右侧系统时钟；44 点触控范围，VoiceOver 返回动作及当前页名称分别标注。正文不重复标题；短内容也不允许让标题跟着页面内缩。保留原有历史详情打开及返回方式，不靠更换导航层级修补布局。

- 高级设置拆为有正确 dismiss 上下文的原生子页；历史／采集选择器、备注、健康权限、帮助、反馈及训练内选择器沿用同一返回入口。没有新增用户提示说明文字。
